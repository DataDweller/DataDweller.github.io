# Module 2 - Perception in the School Shootings Database
![School shootings database by the Washington Post](\assets\images\2026-08-08-perception-in-the-school-shootings-database\school-shootings-database.png)

Source: The Washington Post
Created by John Woodrow Cox, Steven Rich, Lucas Trevor, John Muyskens and Monica Ulmanu 

Visualisation design is not arbitrary, and it's anchored on how human perception processes visual information, concepts I covered in Module 2. I will use preattentive processing, gestalt laws and visual accuracy principles on the above visualisation to demonstrate how they empower us to create compelling visualisations.
 
Preattentively processing applies to this visualisation by how we use quickly notice things like curves for example that points cyclic nature of shootings which could mean the shootings are going to keep happening each one more chaotic and substantial as time goes on. The red streak to is a contrasting colour as everything is black and white and the red just emphasises the curve that much more. The size of the dot clusters growing over time is also a preattentive processing quality. 

Proximity is a law that shows itself in this plot in 2 different ways. First the clustering of little dots shows the sheer number of victims but also denotes each cluster as 1 shooting. Secondly, the spread of all the clusters becomes more widespread which shows growing number of shootings time goes on. 

One quantitative variable shown is the number of students exposed to gun violence. This is represented using equal sized dots with each dot corresponding to a certain number of students. According to visual comparison accuracy principles, this is an effective encoding because viewers compare position and the number of identical marks.
